## Assignment Overview

This mini assignment analyzes Tinkercad from two perspectives: Human-Computer Interaction (HCI) and Computer Graphics (CG).

The purpose of the assignment is to identify important user interface elements in Tinkercad and explain how its 3D graphics features help users interact with and understand objects in a 3D workspace.

## Tool Used

- Tinkercad – Online 3D design and modeling tool
- LaTeX / Overleaf – Used to create and format the assignment presentation

## HCI Focus

Three HCI elements were identified:

1. **Orientation (View) Cube** – Allows users to change the viewing direction of the 3D workspace.
2. **Zoom +/- Controls** – Allow users to zoom in and out of the workspace.
3. **Shape Gallery + Search** – Allows users to find and add shapes easily.

## Computer Graphics Focus

Three Computer Graphics elements were identified:

1. **3D Primitive Meshes** – Demonstrate 3D geometric forms.
2. **Shading & Specular Highlight** – Help objects appear three-dimensional and rounded.
3. **Perspective Grid** – Provides visual cues for perspective and depth.

## Reflections

### Reflection 1 – CG Quality

Shading and perspective help shapes read as real 3D objects, so size and overlap are judged intuitively. However, perspective distortion can hinder precision work because edge objects may appear skewed, complicating exact alignment.

### Reflection 2 – HCI Improvement

I would add clearer labels or tooltips to the main navigation controls. This would help beginners understand the purpose of each control more quickly.
